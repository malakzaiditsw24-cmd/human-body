# 🫀 رحلة داخل جسم الإنسان — لعبة تعليمية تفاعلية

مشروع ويب بسيط (HTML + CSS + JavaScript) بدون أي مكتبات أو تثبيت.

## طريقة التشغيل في VS Code
1. افتح المجلد: **File ▸ Open Folder**.
2. ثبّت إضافة **Live Server** (من Ritwick Dey) من قسم الإضافات.
3. كليك يمين على `index.html` ▸ **Open with Live Server**.

(أو ببساطة اضغط دبل كليك على `index.html` ليفتح في المتصفح.)

> خط **Cairo** يُحمَّل من الإنترنت؛ بدونه تعمل اللعبة بخط النظام.

## الأقسام
| القسم | الوصف |
|---|---|
| 🔍 استكشف الجسم | اضغط على أي عضو لتظهر وظيفته ومكانه ومعلومة طريفة، مع فلتر حسب الجهاز وجولة من الرأس للقدم |
| ❓ اختبر معلوماتك | أسئلة عشوائية في كل مرة (5 / 10 / 16 سؤالًا)، مع شرح بعد كل إجابة ونتيجة بالنجوم |
| 🧩 ركّب الأعضاء | اسحب كل عضو إلى مكانه داخل الجسم (أو اضغط عليه ثم اضغط مكانه)، مع مؤقّت وتلميحات ووضع تحدٍّ بدون خطوط |

## ملفات المشروع
- `index.html` — هيكل الصفحة
- `style.css` — التصميم
- `data.js` — **بيانات الأعضاء** ورسم الجسم (SVG) والأسئلة
- `app.js` — منطق الألعاب

## كيف تضيف عضوًا جديدًا؟
افتح `data.js` وأضف كائنًا جديدًا داخل مصفوفة `ORGANS` بنفس شكل الأعضاء الموجودة
(الاسم، الجهاز، شكل SVG، الوظيفة، المكان، المعلومة، وسؤال). كل شيء في الألعاب الثلاث يتحدّث تلقائيًا.
ترتيب العضو في المصفوفة هو ترتيب رسمه (الأول يظهر في الخلف).
ولإضافته إلى الجولة أضف رقمه في مصفوفة `TOUR`.
